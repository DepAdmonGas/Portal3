# M01 — Lectura SQL de horarios asignados

El propietario autoriza el 26/11/2026 la lectura SQL de asignaciones y plantillas M03/M04 para presentar en M01 el horario asignado por trabajador, localidad y fecha cuando no exista jornada materializada. La lectura usa la conexión institucional existente y el alcance autenticado de M01. Conserva las prioridades y vigencias de programación del lector M03; los conflictos y errores no se presentan como ausencia de programación.

Las jornadas materializadas y sus horarios históricos prevalecen. Esta lectura no materializa jornadas, no evalúa P1/P2, no clasifica marcaciones y no modifica datos. Architecture Freeze V1.0 y J1/J2 permanecen intactos.
