# Capturas del tutorial de bienvenida

Agrega las capturas reales en esta carpeta como archivos WebP. La aplicación
las detectará y mostrará automáticamente cuando sus nombres coincidan con los
espacios de captura del recorrido. Para las capturas animadas se usa de preferencia
`<nombre>.anim.webp`; si no existe o no carga, se utiliza `<nombre>.gif`.
La animación se superpone a la captura WebP estática. Conserva los desenfoques
de privacidad al reemplazar cualquiera de estos archivos.

Se recomienda proporción 16:10 y ancho de 1600 px. Las imágenes se ajustan sin
deformación. Puedes entregar PNG si necesitas conservar texto fino; conviértelo
a WebP antes de integrarlo. Usa datos de demostración y oculta información
personal.

| Archivo | Sección y contenido sugerido |
| --- | --- |
| `bienvenida.webp` | Portada visual del recorrido o Home limpio. |
| `navegacion-sidebar.webp` / `navegacion-sidebar.gif` | Sidebar con categorías y accesos disponibles; el GIF acerca el menú, recorre sus secciones de arriba abajo y vuelve al encuadre completo. |
| `breadcrumbs-periodo.webp` / `breadcrumbs-periodo.gif` | Encabezado con breadcrumbs; el GIF acerca los selectores de mes y año, enseña las opciones y muestra el título después de cada cambio. |
| `cards-componentes.webp` / `cards-componentes.gif` | Cards de Home y componentes; el GIF acerca cada card en orden sin deformar la captura de fondo. |
| `alertas-notificaciones.webp` | Avisos de éxito, advertencia y error. |
| `dropdowns-botones-iconos.webp` / `dropdowns-botones-iconos.gif` | Menú contextual de una solicitud; el GIF amplía el menú y destaca sus opciones una por una. |
| `datatables.webp` | Tabla con búsqueda, filtros, ordenamiento y paginación. |
| `estatus-indicadores.webp` | Columna de estatus con sus indicadores y etiquetas. |
| `modo-oscuro.webp` | Pantalla de Portal3 con el tema oscuro activo. |
| `perfil-foto-telegram.webp` | Perfil con fotografía y estado de vinculación de Telegram. |
| `multiestacion.webp` | Selector de estación/departamento y contexto seleccionado. |

La captura de multiestación sólo se verá en el paso de usuarios con esa
funcionalidad habilitada.
